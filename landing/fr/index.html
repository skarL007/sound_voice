Pourquoi VoiceLaunch

Une voix là où vous parlez vraiment.

Conçu pour les personnes qui ne peuvent pas ou préfèrent ne pas parler, pour les joueurs qui veulent une voix dans le chat, et pour toute personne qui a besoin d'une communication assistée, rapide et privée.

Micro virtuel pour Discord & les jeux

La voix générée est acheminée vers un micro virtuel (VB-Cable, inclus dans l'installateur). Toute application qui lit un micro l'entend : Discord, Zoom, chat vocal en jeu.

Routage Auto intelligent

Edge TTS en ligne quand vous avez internet, repli instantané sur une voix locale (Kokoro/Piper) quand vous êtes hors ligne ou que la connexion tombe. Aucun réglage à changer.

Instantané, sans compte

Des centaines de voix Microsoft Edge naturelles fonctionnent dès l'ouverture de l'application. Rien à télécharger, aucune inscription, aucune télémétrie.

Raccourcis vocaux globaux

Associez une phrase à un raccourci et déclenchez-la depuis un jeu sans quitter la fenêtre. « GG », « couvrez-moi » ou vos propres phrases : une seule touche.

Pensé pour l'accessibilité

Historique et brouillon persistants, phrases rapides, clavier virtuel, modes contraste élevé et grande police, navigation complète au clavier, focus visible.

Gratuit & open source

Licence MIT, pas de version payante, aucune collecte de données. La synthèse locale ne quitte jamais votre machine. Contributions bienvenues.

Fonctionnement

Tapez → routage → parlez dans n'importe quel chat vocal.

Le mode Auto choisit le meilleur moteur pour chaque phrase et diffuse l'audio vers votre micro virtuel pour que Discord et les jeux l'entendent, tout en vous laissant vous entendre vous-même.

Voix

Qualité cloud par défaut, local quand il le faut.

Le mode Auto choisit le moteur local selon votre matériel. Le parcours local recommandé est Piper d'abord, puis Kokoro pour une meilleure qualité.

Installation

Opérationnel en trois étapes.

Windows 10/11 x64. Le micro virtuel est inclus et se configure tout seul.

1

Télécharger

Récupérez le dernier VoiceLaunch-TTS-Setup.exe sur les Releases GitHub et lancez-le. VB-Cable s'installe automatiquement.

2

Activer le micro

Ouvrez l'application, activez le micro virtuel (il sélectionne automatiquement CABLE Input), tapez une phrase et cliquez sur Parler.

3

Pointer Discord dessus

Dans Discord (ou n'importe quel jeu), définissez le périphérique d'entrée sur CABLE Output. Toutes les personnes du salon entendent désormais votre voix.

Windows SmartScreen : cette version open source n'est pas signée : Windows affiche « Windows a protégé votre ordinateur ». Cliquez sur Informations complémentaires → Exécuter quand même. Chaque version publie le SHA-256 de l'installateur pour que vous puissiez le vérifier au préalable : 
Get-FileHash -Algorithm SHA256 .\VoiceLaunch-TTS-Setup.exe
